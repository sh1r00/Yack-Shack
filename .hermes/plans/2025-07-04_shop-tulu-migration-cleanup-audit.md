# shop-tulu — Migration, Cleanup & Audit Plan

> **For Hermes:** Use `subagent-driven-development` skill to implement this plan task-by-task.

**Goal:** Migrate shop-tulu from Nuxt 3.7.4 to Nuxt 4, fix all code bugs, modernize architecture, and harden the codebase.

**Architecture:** Shopify Storefront e-commerce PWA built on Nuxt + Apollo GraphQL + Storefront UI v2 + Pinia + TailwindCSS. 40 components, 4 stores, 7 pages, 19 Apollo queries/mutations, PWA, Nuxt Content, Winston logging.

**Tech Stack:** Nuxt 4, Vue 3.5+, TypeScript, Apollo Client, Pinia (Composition API), TailwindCSS v3, Storefront UI v2, @vite-pwa/nuxt, Nuxt Content, Vitest


**Step 2: Install**
```bash

```

**Step 3: Move `head` to `app.head` in nuxt.config.ts**

The `head` key is deprecated in Nuxt 3 and **removed** in Nuxt 4. Move everything to `app.head`:

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  app: {
    head: {
      title: 'Shopify | Vue Storefront Next',
      meta: [ /* ... */ ],
      link: [ /* ... */ ]
    }
  },
  // Remove the old `head` block entirely
  // Remove the old `loading` block (removed in Nuxt 3+)
})
```

**Step 4: Remove deprecated config keys**
- Remove `loading: { color: colorPrimary }` — removed in Nuxt 3
- Remove `build.transpile` — use Nitro `experimental.externalVue` or vite config instead
- Remove `vite.vue.customElement: true` — likely not needed

**Step 5: Test build**
```bash
npm run build
```
Expected: build succeeds (may have warnings — those come next)

### Task D6: Add composables for reusable logic

**Objective:** Extract duplicated logic into composables

**Files:**
- Create: `composables/useCollection.ts`
- Create: `composables/useProduct.ts`

**Step 1: Create `composables/useCollection.ts`**
```ts
export function useCollection(handle: string) {
  const { resolveClient } = useApolloClient()
  const loading = ref(false)
  const error = ref<string | null>(null)
  const collection = ref(null)

  async function fetch() {
    loading.value = true
    error.value = null
    try {
      const client = resolveClient()
      const { data } = await client.query({
        query: collectionByHandle,
        variables: { handle }
      })
      collection.value = data.collectionByHandle
    } catch (e) {
      error.value = e instanceof Error ? e.message : 'Unknown error'
    } finally {
      loading.value = false
    }
  }

  return { collection, loading, error, fetch }
}
```

**Step 2: Create `composables/useProduct.ts`**
